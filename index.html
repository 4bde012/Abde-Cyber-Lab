Herramienta web para analizar registros de seguridad

ABDE CYBER TOOLS es una herramienta web gratuita para revisar archivos de registro en formato TXT o LOG. Ayuda a organizar eventos de acceso y a localizar patrones que pueden necesitar una revisión.

¿Qué puedes analizar?

La herramienta reconoce registros de ejemplo con eventos LOGIN_OK y LOGIN_FAIL, nombre de usuario y dirección IP. Resume los accesos correctos y fallidos, cuenta los fallos por IP y muestra avisos orientativos para facilitar la revisión manual.

Privacidad y uso responsable

El análisis se realiza en el navegador. El historial se guarda localmente en este navegador y no se envía a un servidor mediante las funciones de análisis de esta página. Utiliza únicamente archivos propios o registros que tengas permiso para revisar.

Cómo empezar

Abre el analizador, selecciona un archivo TXT o LOG compatible y pulsa «Analizar registro». Puedes revisar el informe, consultar el historial y exportar el resultado como archivo de texto. Los avisos son orientativos y no confirman por sí solos que exista un ataque.

Las alertas son orientativas. Un acceso fallido no demuestra por sí solo que exista un ataque. El historial se guarda únicamente en este navegador.
